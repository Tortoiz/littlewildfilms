## About the film

Mosslight began as a question: can a place hold a memory without turning it into a ghost story?

The project uses generative tools as a sketchbook for a forest that changes with every person who enters it.

## The experiment

Rather than asking a model for a finished image, we are using it to discover the edges of a world — then bringing those discoveries back into a more deliberate filmmaking process.
